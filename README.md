# RPG Maker 游戏内中文翻译 · D 盘诊断版

免费提供下载和试用的 RPG Maker MV/MZ 中文翻译工具。通过插件在游戏原来的对话框、选项和菜单位置显示译文。

> **实验诊断版：尚未完成 Windows 实机和真实游戏的端到端验证。此前 EXE 版出现过无法启动的问题；本版通过保留命令行窗口帮助排查。请不要视为稳定正式版。**
>
> 本项目为自制工具，与 MTool 官方无关联。

## 下载

**[点击下载 D 盘诊断版 ZIP](https://github.com/bdzzwm/rpg-/raw/refs/heads/main/downloads/RPGTranslator_D_Diagnostic.zip)**

下载位置由浏览器决定。请在浏览器选择“另存为”，保存至 D 盘。

## 使用方法

1. 关闭游戏，将 ZIP **全部解压到 D 盘**，不要直接在压缩包中运行。
2. 双击 `Start_Diagnostics.cmd`，保留打开的命令行窗口。
3. 正常启动时会出现安装界面。选择 D 盘中 **Game.exe 所在的文件夹**，或游戏的 `www` 文件夹。
4. 点击“安装中文翻译”，阅读联网提示，再正常启动游戏。
5. 按 **F6** 或点击游戏右上角按钮暂停/恢复翻译。
6. 如果启动失败，请保留报错文字。反馈截图前遮住姓名、账号、个人路径等不想公开的信息。

如果已安装旧版，先关闭游戏，使用本版“卸载还原”，再安装。不要手动删除游戏目录里的安装备份。

## 文件保存位置

| 内容 | 保存位置 |
| --- | --- |
| 诊断版程序和运行目录 | 你在 D 盘解压的文件夹及其中的 `runtime` |
| 译文缓存 | `D:\RPGTranslator\cache` |
| 游戏插件及安装备份 | 你选择的 D 盘游戏目录 |

仅允许选择实际位于 D 盘的游戏，拒绝目录链接。D 盘缓存不可写时只使用内存，不退回 C 盘缓存。Windows、浏览器及游戏自身的系统记录、用户数据或存档位置不受本工具完全控制。旧版留下的游戏 localStorage 缓存不自动删除，以免误删存档。

## 支持与限制

- Windows 10/11，自带 Windows PowerShell 5.1；无需 Python。
- 普通 NW.js 桌面版 RPG Maker **MV/MZ**，使用标准插件列表。
- **不支持 XP、VX、VX Ace**、封装/加壳游戏及网页链接。
- 图片里的文字、自定义绘制界面及第三方消息插件可能无法翻译。
- 首次出现的文字需要联网。对话会等待翻译，超时后保留原文；菜单可能先显示原文再刷新。
- 译文缓存最多 4000 条；原换行和标准控制符受到保护，但长译文可能超框。
- 不改写原始数据库或存档；安装会修改插件列表并加入插件，卸载提供备份校验。

## 联网与隐私

游戏文字通过 HTTPS 发送至 **Google 翻译的实验性公开网页接口**。不需要账号或 API 密钥，不上传截图。该接口不是有可用性保证的官方开发者 API，可能限流、变更或无法连接；不能保证永久免费可用或所有网络可达。机翻质量也不作保证。

程序没有设置开机自启动。启动游戏后插件会随游戏加载；退出游戏后插件停止运行。诊断窗口需要手动关闭或按提示结束。
